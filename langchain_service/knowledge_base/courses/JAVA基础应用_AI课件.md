# 《JAVA基础应用》教学课件

## 一、课程概述

### 课程简介
《JAVA基础应用》是计算机相关专业的一门专业基础课，旨在帮助学生系统掌握Java编程语言的核心语法、面向对象思想及基础类库的使用。课程理论与实践并重，通过大量编程实例，培养学生利用Java解决实际问题的基本能力，为后续的Java Web开发、Android开发等课程打下坚实基础。

### 教学目标
- **知识目标**：掌握Java基本语法、控制流程、数组和方法；深刻理解面向对象三大特性（封装、继承、多态）；熟练使用常用类库。
- **能力目标**：能够运用面向对象思想分析和设计程序；能独立编写、调试和运行中小规模的Java应用程序。
- **素养目标**：培养严谨的编码风格和规范的注释习惯；提升逻辑思维与问题求解能力。

### 适用对象
计算机科学与技术、软件技术、大数据技术等专业的高职或本科一、二年级学生。要求学习者具备一定的计算机基础操作能力，无需编程基础。

### 参考学时
理论教学28学时，上机实践28学时，总计56学时。

## 三、详细教学内容

### 模块一：Java入门与环境搭建

#### 1.1 Java语言发展史与特点
Java由Sun公司（现Oracle）于1995年正式发布，历经多年发展，形成了Java SE（标准版）、Java EE（企业版）、Java ME（微型版）三大平台。其核心特点包括：
- **跨平台性**：一次编译，到处运行，依赖Java虚拟机（JVM）。
- **面向对象**：纯粹的对象导向设计，支持封装、继承、多态。
- **健壮性**：强类型机制、异常处理和自动垃圾回收。
- **多线程与动态性**：内置多线程支持，可动态加载类。

#### 1.2 JDK安装与配置
- **JDK与JRE**：JDK包含JRE及开发工具（javac、java等），JRE仅提供运行环境。
- **环境变量**：需配置`JAVA_HOME`（JDK安装路径）和`Path`（添加`%JAVA_HOME%\bin`），便于在命令行调用编译和运行命令。
- **验证**：命令行输入`java -version`及`javac -version`确认安装成功。

#### 1.3 第一个Java程序
```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```
**重点**：类名与文件名必须完全一致（包括大小写）；main方法是程序的入口；字符串使用双引号。  
**难点**：理解`public static void main(String[] args)`每个关键字的作用。

#### 1.4 程序运行机制
- **编译**：`javac HelloWorld.java` 生成字节码文件`HelloWorld.class`。
- **运行**：`java HelloWorld` 由JVM加载字节码并解释执行。
- **JIT即时编译**：对热点代码编译成本地机器指令，提升性能。

### 模块二：Java基本语法

#### 2.1 标识符、关键字与注释
- **标识符规则**：由字母、数字、下划线、$组成，数字不能开头，不能使用关键字，区分大小写。
- **关键字**：共50个，如`class`、`new`、`int`等，`goto`、`const`为保留字。
- **注释**：单行注释`//`，多行注释`/* */`，文档注释`/** */`（可生成API文档）。

#### 2.2 数据类型与常量
- **基本数据类型（8种）**：byte(1字节)、short(2)、int(4)、long(8)、float(4)、double(8)、char(2)、boolean(1位)。
- **引用数据类型**：类、接口、数组等。
- **常量**：使用`final`关键字修饰，命名习惯全大写，如`final double PI = 3.14;`。
**重点**：整数默认int，浮点数默认double；long型需加`L`后缀，float加`F`后缀。

#### 2.3 变量与作用域
变量必须先声明后使用，其作用域在包含它的花括号内。成员变量有默认值（int为0，引用为null），局部变量必须显式初始化。

#### 2.4 运算符与表达式
- 算术运算符：`+  -  *  /  %` （整数除法直接截断，`%`可作用于浮点数）
- 关系运算符：`> < >= <= == !=`
- 逻辑运算符：`&& || !`（短路特性）
- 赋值运算符：`= += -= *= /= %=`
- 位运算符：`& | ^ ~ << >> >>>`
- 三元运算符：`条件 ? 表达式1 : 表达式2`
**难点**：自增自减前缀后缀的区别；逻辑运算符的短路效果。

#### 2.5 类型转换
- **自动类型提升**：小类型赋值给大类型（如int转double）。
- **强制类型转换**：大类型转小类型可能丢失精度，格式为`(目标类型) 值`。
- char与int可互相转换，遵循Unicode编码。

### 模块三：流程控制

#### 3.1 分支结构
- **if-else**：可嵌套、多分支`if-else if-else`。**注意**大括号不要省略以避免歧义。
- **switch**：表达式支持byte、short、int、char、String（JDK7+）及枚举。每个case需要break；`default`可放在任意位置。

#### 3.2 循环结构
- **for**：`for(初始化; 条件; 迭代){}`，适合已知次数循环。
- **while**：先判断后执行。
- **do-while**：至少执行一次。
- 增强for循环（`for(元素类型 变量 : 容器)`）用于遍历数组和集合。

#### 3.3 跳转语句
- `break`：终止当前循环或switch。
- `continue`：跳过本次循环剩余部分，进入下一次迭代。
- `return`：结束方法执行，并可返回结果。

**案例**：打印九九乘法表，综合运用嵌套循环和输出格式控制。

### 模块四：数组与方法

#### 4.1 一维数组
- **声明**：`int[] arr;` 或 `int arr[];`
- **静态初始化**：`int[] arr = {1,2,3};`
- **动态初始化**：`int[] arr = new int[5];` 默认值为0。
- **长度**：`arr.length`属性返回数组长度，不可变。
- **遍历**：使用普通for或增强for。**难点**：数组索引越界异常ArrayIndexOutOfBoundsException。

#### 4.2 二维数组
理解为数组的数组。`int[][] matrix = new int[3][4];`，`matrix.length`为行数，`matrix[i].length`为第i行列数。不规则二维数组允许各行长度不同。

#### 4.3 方法的定义与调用
- **定义格式**：
  ```java
  修饰符 返回值类型 方法名(参数列表) {
      方法体;
      return 返回值; // 如果void无返回，可不写或仅写return;
  }
  ```
- **调用**：同类方法直接调用，不同类通过对象调用。
- **形参与实参**：基本类型传值（拷贝），引用类型传地址值。

#### 4.4 方法重载（Overload）
同一个类中方法名相同，参数列表不同（个数、类型、顺序），与返回值类型无关。重载方便调用者记忆。

#### 4.5 方法递归
方法自己调用自己。必须定义递归头（终止条件）和递归体。  
**案例**：计算阶乘和斐波那契数列，同时强调递归可能导致栈溢出（StackOverflowError）。

### 模块五：面向对象基础

#### 5.1 类与对象
- **类**是抽象模板，**对象**是具体实例。使用`new 类名()`创建对象。
- 成员变量（属性）描述状态，成员方法（行为）描述功能。

#### 5.2 构造方法
- 与类同名，无返回值。若不定义，系统默认提供无参构造；若定义了有参构造，默认无参构造消失，建议手动添加。
- **this关键字**：代表当前对象的引用，用于区分成员变量和局部变量同名的情况，也可在构造器中调用本类其他构造器`this(参数)`（必须写在构造器第一行）。

#### 5.3 封装与访问修饰符
- **封装**：隐藏对象内部细节，提供公共访问方式。通过`private`修饰成员变量，并设置`public`的getter/setter方法。
- **访问修饰符**：`private`（本类可见）、默认（同包可见）、`protected`（同包及子类）、`public`（全部可见）。

#### 5.4 static关键字
- 修饰变量：类变量，属于类，所有对象共享。
- 修饰方法：类方法，可直接用类名调用，内部不能直接访问非静态成员。
- 静态代码块：类加载时执行一次，用于初始化静态资源。
**重点**：静态方法不能使用`this`。

#### 5.5 单例模式初步
设计一个类只能创建一个实例。饿汉式：类加载时即创建对象；懒汉式：初次调用时创建（需考虑线程安全）。代码示例：
```java
public class Singleton {
    private static Singleton instance = new Singleton();
    private Singleton() {}
    public static Singleton getInstance() { return instance; }
}
```

### 模块六：面向对象高级

#### 6.1 继承
- 使用`extends`实现，Java单继承。
- 子类继承父类非私有成员。子类构造器默认调用父类无参构造`super()`，若无，则需显式调用有参构造。
- **super**：访问父类成员，调用父类方法或构造器。

#### 6.2 方法重写（Override）与多态
- **重写**：子类对父类可访问方法进行重新实现，要求方法签名相同，返回类型可协变，访问权限不能更严格。
- **多态**：父类引用指向子类对象 `Parent p = new Child();`。
- 成员变量看左边（父类），成员方法看右边（子类），即编译看左边运行看右边。
- 多态的应用场景为方法参数和返回值类型使用父类型。

#### 6.3 抽象类与接口
- **抽象类**：使用`abstract`修饰，可包含抽象方法（无方法体）和具体方法。不能实例化，需要子类继承并实现所有抽象方法。
- **接口**：使用`interface`定义，类似完全抽象类，JDK8后允许默认方法和静态方法。类通过`implements`实现接口，可多实现。
- **区别**：抽象类体现“is-a”关系，接口体现“has-a” / “like-a”能力。接口实现强调规范与解耦。

#### 6.4 内部类
成员内部类、局部内部类、匿名内部类。匿名内部类常用于快速创建接口或抽象类的实现对象。

### 模块七：常用类库与异常处理

#### 7.1 字符串相关类
- **String**：不可变字符序列，常量池优化。常用方法：`length()`、`charAt()`、`substring()`、`equals()`、`indexOf()`、`split()`等。
- **StringBuilder**：可变字符序列，非线程安全但效率高，用于频繁字符串拼接。方法：`append()`、`insert()`、`reverse()`。

#### 7.2 包装类
把8种基本类型包装成对象。`int -> Integer`，`char -> Character`，其他首字母大写。  
- **自动装箱**：`Integer i = 10;`（底层调用`valueOf`）
- **自动拆箱**：`int a = i;`（调用`intValue`）
- 提供类型转换方法（如`parseInt`）。

#### 7.3 其他常用类
- **Math**：数学运算，如`abs`、`max`、`random`（0.0~1.0）。
- **Random**：生成伪随机数，`nextInt(100)`。
- **Scanner**：获取键盘输入，`Scanner sc = new Scanner(System.in);` `nextInt()`、`nextLine()`。

#### 7.4 异常处理机制
- **异常体系**：Throwable下分Error（不可处理）和Exception（可处理）。Exception分为RuntimeException（非受检）和其他Exception（受检）。
- **try-catch-finally**：捕获异常，finally代码总会执行（除非System.exit）。
- **抛出异常**：方法内`throw new Exception()`，方法签名上`throws`声明。
- **自定义异常**：继承Exception或RuntimeException，提供构造方法。

**案例**：模拟银行取款，金额不足时抛出自定义`InsufficientFundsException`。

### 模块八：集合框架入门

#### 8.1 集合体系
- Collection接口：List（有序可重复）、Set（无序不重复）、Queue。
- Map接口：键值对存储，键不可重复。

#### 8.2 List集合
- **ArrayList**：基于数组实现，查询快增删慢，线程不安全。
- **LinkedList**：双向链表，增删快查询慢。
- 常用方法：`add`、`remove`、`get`、`set`、`size`。

#### 8.3 Set集合
- **HashSet**：基于HashMap实现，元素唯一且无序，要求元素重写`hashCode()`和`equals()`方法。
- **TreeSet**：可排序，元素必须实现Comparable接口或传入Comparator。

#### 8.4 Map集合
- **HashMap**：基于哈希表，允许null键和值，无序，线程不安全。
- **TreeMap**：基于红黑树，按键自然排序。
- 常用方法：`put`、`get`、`remove`、`containsKey`、`keySet`、`entrySet`。

#### 8.5 遍历集合
- 使用`Iterator`迭代器：
  ```java
  Iterator<Type> it = list.iterator();
  while(it.hasNext()){ Type t = it.next(); }
  ```
- 增强for循环内部就是使用迭代器，不能在遍历中通过集合删除元素，可使用迭代器的`remove`方法避免并发修改异常。

## 四、课后习题

1. **简答题**：请简述Java程序“一次编译，到处运行”的实现原理，并说明JVM的作用。
2. **编程题**：编写一个方法，接收一个整型数组，返回数组中的最大值和最小值，并运用多态设计思想输出结果（例如将数组定义为父类引用但实际使用子类增强）。要求同时给出调用示例。
3. **概念辨析**：阐述方法重载（Overload）和方法重写（Override）的区别，结合代码举例说明。
4. **综合设计**：定义一个抽象类Animal，包含抽象方法sound()；派生出Dog类和Cat类，重写sound()。再定义一个Test类，使用多态方式将不同的Animal对象放入ArrayList，通过增强for循环调用sound()。最后通过用户输入动物类型动态创建对应对象。
5. **纠错分析**：以下代码存在哪些编译或运行时错误？并修改使其正常运行。
   ```java
   public class Test {
       public static void main(String[] args) {
           List<int> list = new ArrayList<>();
           list.add(1);
           list.add("2");
           for (int i = 0; i <= list.size(); i++) {
               System.out.println(list.get(i));
           }
       }
   }
   ```

### 参考答案（要点）
1. Java源文件(.java)经编译生成字节码(.class)，字节码与平台无关。不同操作系统安装对应JVM，JVM负责加载字节码并解释或即时编译执行，从而屏蔽底层差异。
2. 方法：`public static int[] getMaxMin(int[] arr)` 遍历比较。多态设计略，可考虑建立Result父类和打印方法。调用示例略。
3. 重载在同一类中方法名相同参数列表不同；重写发生在父子类间，方法签名一致，运行时动态绑定，多态实现基础。代码示例略。
4. 抽象类和实现类定义略。`ArrayList<Animal> list = new ArrayList<>();` 添加对象，循环调用`sound()`。使用`Scanner`输入和`if`判断动态实例化对象。
5. 错误：泛型不能用基本类型，应为`List<Integer>`；添加字符串"2"类型不匹配；循环条件`i <= list.size()`会越界，应为`i < list.size()`。
